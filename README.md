# Facebook Login Page

A Facebook-inspired login page UI built using **HTML5 and Tailwind CSS**, featuring a clean layout, login form, and account creation section.

## ✨ Features

- Clean and minimal user interface
- Email or Phone Number input field
- Password input field
- Login button
- Forgotten Password option
- Create New Account button
- Styled using Tailwind CSS

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS

## 📚 What I Learned

- HTML page structuring
- Tailwind CSS utility classes
- Flexbox and layout alignment
- Styling forms, buttons, and input fields
- Creating clean web interfaces

## ⚠️ Disclaimer

This project is developed for educational and frontend practice purposes only. It is not affiliated with or endorsed by Meta or Facebook. No actual authentication functionality is implemented.
